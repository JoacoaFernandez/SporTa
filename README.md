# 🏟️ Sporta

**Sporta** es una aplicación para reservar canchas deportivas de forma rápida y sencilla. Conecta a jugadores con complejos deportivos, permitiendo ver disponibilidad en tiempo real, reservar y pagar online.

## 📌 Estado del proyecto

🚧 En desarrollo — versión inicial (MVP)

## ✨ Funcionalidades

### MVP
- [ ] Registro e inicio de sesión de usuarios
- [ ] Búsqueda de canchas por deporte, ubicación, precio y horario
- [ ] Calendario de disponibilidad en tiempo real
- [ ] Reserva y pago online
- [ ] Perfil de jugador y perfil de dueño de cancha
- [ ] Notificaciones de confirmación y recordatorio

### Roadmap futuro
- [ ] Matchmaking para completar equipos o buscar rivales
- [ ] Reseñas y calificaciones de canchas
- [ ] Reservas recurrentes (ligas, torneos, grupos fijos)
- [ ] Mapa con geolocalización
- [ ] Panel de administración para dueños (precios dinámicos, bloqueos, estadísticas)
- [ ] Política de cancelación y reembolsos
- [ ] Invitar amigos / compartir reserva
- [ ] Programa de puntos o descuentos
